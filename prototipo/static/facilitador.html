El celular debe estar en la misma red que este computador. Si hay varias, elijan cuál va en el código QR:

¿El celular escanea y no carga? No es el prototipo: el wifi de la universidad no deja que dos aparatos se vean entre sí. Hay que armar una red aparte solo para la prueba (el celular no necesita internet, solo ver este computador):
  1. Plan A: doble clic en PUNTO_DE_ACCESO.bat (carpeta del prototipo). Prende el punto de acceso de Windows y muestra la clave. Conecten el celular a esa red.
  2. Plan B, si el computador no deja: prendan el hotspot de un celular y conecten este computador a esa red. No gasta datos.
  3. Vuelvan a esta lista: la dirección nueva (192.168.137.x o 192.168.43.x) aparece sola. Selecciónenla y el QR del televisor cambia solo, sin reiniciar el caso.
